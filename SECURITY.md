# Security Policy

This is a hobby project. Best effort support will be provided to mitigate
and fix security issues (we use it ourselves!) but it should not be
relied upon for critical production use-cases unless you are prepared to
provide your own support.

## Supported Versions

Only the latest docker container is considered supported.

## Reporting a Vulnerability

Report vulnerabilities through Github or via the email address of the
majority contributor (see commits).
